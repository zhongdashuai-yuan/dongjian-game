# 洞见 · Dongjian

> 重庆，一座被时间折叠的城市。
>
> 你跟着一只叫「渝灯」的灯笼精灵，从洪崖洞的夜色里出发，沿着一条蓝金色的时间轨迹往回走 ——
> 你会看见磁器口窑场昼夜不熄的炉火，泥土在匠人手中烧成器；
> 你会走在雨中古镇的石板路上，布匹沿江而行，商旅的故事落在水洼里；
> 你会钻进 1941 年的防空洞，听着脚步回声，看人们把灯火藏进山洞，也把希望留在这里；
> 最后你回到现代，高楼沿江而起，旧日灯火变成了今天的万家灯火。
>
> **这不是一段旅游。**
> **你走过的每一步，都是别人拼命活下来的路。**

**类型**：2D 解谜 · 叙事探索
**引擎**：Godot 4.4.7　|　**平台**：Windows 64 位　|　**版本**：v1.0
**作者**：钟袁刘马

或者到 [Releases 页面](../../releases/latest) 查看。

### 怎么运行

1. 用 **7-Zip** 或 **WinRAR** 解压（Windows 自带解压对中文文件名支持不好，可能乱码）
2. 解压后得到一个文件夹，里面有 **两个文件**：`洞见.exe` 和 `洞见.pck`
3. 双击 `洞见.exe` 开始游戏

> ⚠️ **重要**：`洞见.exe` 和 `洞见.pck` **必须放在同一个文件夹里**。
> `.pck` 是游戏资源包，单独把 `.exe` 拷到别处是打不开的（会提示缺少资源）。

### 运行环境

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11 64 位 |
| 显卡 | 支持 OpenGL 3.3 或 Vulkan 的显卡（核显也能跑） |
| 磁盘 | 约 300 MB 可用空间 |
| 其他 | 无需安装，绿色免安装 |

如果双击没反应或提示缺少 DLL，通常是缺少
[Visual C++ 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe)，装一下即可。

## 走进「洞见」

游戏沿着一条**蓝金色的时间轨迹**往回走，途经几段重庆的时间切片：

| 场景 | 你会在那里看到 |
|---|---|
| **洪崖洞的夜色** | 旅程的起点，跟着灯笼精灵「渝灯」出发 |
| **磁器口窑场** | 昼夜不熄的炉火，泥土在匠人手中烧成器 |
| **雨中古镇** | 石板路、沿江而行的布匹，商旅的故事落在水洼里 |
| **1941 年的防空洞** | 脚步的回声，人们把灯火藏进山洞，也把希望留在这里 |
| **现代重庆** | 高楼沿江而起，旧日灯火变成今天的万家灯火 |
